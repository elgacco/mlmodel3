# Прогноз недельного спроса на товары

ML-проект для прогнозирования недельных продаж товаров интернет-магазина. Модель CatBoost предсказывает количество единиц товара, которое будет продано в заданную неделю. Решение оформлено как воспроизводимый inference-модуль: модель, история продаж и описание признаков поставляются вместе с кодом.

## Задача

Для пары **(код товара, неделя)** предсказать суммарное количество проданных единиц.

Прогноз может использоваться для:

- планирования закупок;
- управления товарными запасами;
- снижения риска дефицита ходовых товаров;
- подготовки к сезонным пикам спроса.

## Данные

Источник — [Online Retail Dataset](https://docs.google.com/spreadsheets/d/1OhYXM7MP6i6fMFEc_cl01AHvWiUkZcQQ/edit?usp=sharing): транзакции интернет-магазина за период с декабря 2010 по декабрь 2011 года.

При подготовке данных были удалены отменённые заказы, возвраты, служебные позиции, строки с некорректными количеством или ценой и полные дубликаты.

Для модели отобраны **288 товаров**, которые продавались в каждую из 53 недель наблюдений. Продажи агрегированы до уровня:

```text
StockCode × week
```

## Признаки

Для прогноза используются только данные, доступные до запрошенной недели.

| Группа | Признаки |
| --- | --- |
| Лаги продаж | `lag_1`, `lag_2`, `lag_4`, `lag_8` |
| Скользящие статистики | `roll_mean_4`, `roll_mean_8`, `roll_max_4` |
| Календарные признаки | `week_num`, `month_num`, `quarter_num`, `weeks_since_start` |
| Категориальный признак | `StockCode` |

Порядок признаков хранится в `model/meta.json`. Благодаря этому сервис формирует входные данные в точно таком же формате, в котором модель обучалась в ноутбуке.

## Модель

Используется `CatBoostRegressor` с функцией потерь MAE.

Разделение данных выполнено по времени:

| Выборка | Период |
| --- | --- |
| Train | до 1 сентября 2011 |
| Validation | сентябрь–октябрь 2011 |
| Test | ноябрь–декабрь 2011 |

### Результаты

| Модель | MAE | RMSE | WAPE, % |
| --- | ---: | ---: | ---: |
| Baseline: продажи прошлой недели | 94.52 | 202.74 | 71.74 |
| Baseline: среднее за 4 недели | 78.95 | 167.69 | 59.93 |
| **CatBoost, validation** | **69.70** | **163.91** | **52.91** |
| CatBoost, test | 82.75 | 226.76 | 53.66 |

Наиболее важные признаки: `roll_mean_8`, `StockCode`, `roll_mean_4`, `lag_1` и `lag_2`.

## Как работает прогноз

Клиент передаёт только:

- `stock_code` — код товара;
- неделю, для которой нужен прогноз.

История продаж не передаётся в запросе: она загружается один раз при старте из `model/weekly_sales.csv`.

Процесс выглядит так:

```text
stock_code + week
        ↓
поиск истории товара
        ↓
расчёт признаков по данным до указанной недели
        ↓
CatBoost-модель
        ↓
прогноз продаж ≥ 0
```

Если товара нет среди доступных 288 товаров или для указанной недели недостаточно истории, сервис возвращает понятную ошибку.

## Тесты

Тесты проверяют ключевую часть ML-пайплайна — идентичность признаков и прогнозов при обучении и при inference.

```bash
pytest
```

Покрываются сценарии:

- прогноз через `predict.py` совпадает с прогнозом `model.predict` на примерах из validation и test;
- неизвестный код товара вызывает ошибку;
- недостаточная история для расчёта лагов и скользящих статистик вызывает ошибку.

Критерий корректности: для одинаковых `stock_code` и недели прогноз сервиса должен совпадать с прогнозом модели из ноутбука с нулевой разницей.
